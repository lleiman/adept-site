02 / The system

Virality is not a prompt.

The weak approach is collecting tools. The useful approach is building a loop where every post teaches you what to make next.

01

Pattern mining

Find ideas with a visual contradiction, emotional charge or instantly legible premise.

02

Hook architecture

Design the first 1–2 seconds before you generate anything. If the hook fails, polish does not save it.

03

AI visual pipeline

Build consistent frames, camera logic and motion with a minimal tool stack.

04

Edit for retention

Remove dead time, create micro-payoffs and use sound as structure instead of decoration.

05

Publish + iterate

Read retention, saves, shares and comments as creative feedback — then make the next variant.
