# Psychology Content OS

Operational dashboard for a psychology/consciousness media system.

Flow:
1. English-language trend radar
2. Core thesis selection
3. Daily production pack
4. Human approval
5. Distribution across Telegram, Instagram/Shorts, X, YouTube and Reddit
6. Performance memory

Environment variables:
- `TREND_SOURCE_URL` — JSON endpoint for Trend Radar
- `TREND_FALLBACK_JSON` — optional fallback array
- `CONTENT_PIPELINE_JSON` — generated content packs array
- `CONTENT_TIMEZONE` — defaults to Asia/Makassar
